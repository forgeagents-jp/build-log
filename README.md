# build-log
Public scratchpad for experiments, demos, and small builds.

Pushes and releases here fire a webhook into a Discord channel where a few of us work in public — so this repo doubles as a live feed of what's actually being built.

What lives here
Throwaway experiments and spikes
Small self-contained demos worth showing someone
Notes and snippets from things that worked (or didn't)

Nothing here is production. Nothing here is client work.

What never lives here
API keys, tokens, credentials, .env files — in any commit, including history
Customer, patient, or practice data of any kind
Anything from a private repo, copied or otherwise

Every commit message in this repo is broadcast to a Discord channel the moment it lands. Assume strangers read it, because they do. If a commit message would be a problem in public, the work doesn't belong in this repo.

Working here

Commit messages are the feed. Write them for a human reading over your shoulder, not for a changelog. Small commits beat big ones — they make better posts and better history.

Why public

Building where people can see it is the point. The Discord side is for AI news, build logs, and co-working sessions; this repo is the part of that which has a git history.
